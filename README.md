# UK Theme Park Queues

Mobile-first personal PWA for viewing live UK theme-park queue times.

## iPhone
Open the deployed HTTPS link in Safari. To install without the App Store:
1. Tap Share.
2. Tap **Add to Home Screen**.
3. Launch **UK Queues** from the Home Screen.

## Deployment
This is a static site. Upload the files to GitHub Pages, Netlify, Cloudflare Pages, or Vercel.
No database or server is needed for this first version.

## Live data
The app reads the ThemeParks.wiki public API and refreshes every five minutes.
